# Data Governance and Research Integrity

1. NISR data are the primary official statistical source for the project.
2. Every external dataset will be cited with provider, version/date, license and access date.
3. Restricted microdata will not be published in the public GitHub repository.
4. Only permitted/aggregated outputs will be shared publicly.
5. Data cleaning and transformation scripts will be reproducible.
6. The project will distinguish descriptive statistics, association, prediction and causal inference.
7. Model performance will be reported with validation metrics, not only training accuracy.
8. Known limitations will be visible in the application.
9. AI assistance will be disclosed in the final submission in accordance with NISR rules.
10. The team will confirm that the final submission is original and has not been submitted to another competition.
