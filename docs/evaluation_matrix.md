# NISR 2026 Evaluation Evidence Matrix

| NISR criterion | Weight | RAPIS evidence | Judge-facing proof |
|---|---:|---|---|
| Problem Understanding & Relevance | 20 | Agricultural productivity gaps; Track 1 irrigation and soil-conservation focus; NST2/Vision 2050 alignment | One clear decision question + policy map |
| Data Use & Methodology | 20 | NISR Season B data, preprocessing, district-held-out ML, reproducible pipeline | Data source panel + validation metrics + methodology page |
| Tech Innovation | 20 | R/Shiny, Extra Trees benchmark, transparent targeting, geospatial/climate-ready architecture | Live ML + targeting + map/scenario demonstration |
| Usability & Design | 20 | Decision Center, filters, profiles, interactive charts, downloads | One simple user journey from question to action |
| Tangible Impact | 20 | Planner-facing district evidence, intervention targeting, future climate/soil/satellite modules | Example decision workflow + measurable implementation KPIs |

## Track 1 coverage

| NISR Track 1 focus | RAPIS status |
|---|---|
| Small-scale irrigation | Current evidence + targeting component |
| Soil conservation/fertility | Current erosion evidence; soil connector ready |
| Post-harvest collection/storage | Future module; requires approved data |
| Processing/value addition | Future module; requires approved data |
| Export opportunities | Future module; requires approved trade/export data |

## Submission requirements

NISR 2026 expects a public GitHub link, deployed app link and documentation. These should be tested before submission.
