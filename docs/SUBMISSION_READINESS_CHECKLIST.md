# RAPIS — NISR 2026 Submission Readiness Checklist

## Mandatory submission items

- [ ] Public GitHub repository
- [ ] Deployed application link
- [ ] Documentation
- [ ] Team information and eligibility documents
- [ ] Source/data acknowledgements
- [ ] AI assistance disclosure
- [ ] Originality/plagiarism declaration

## Technical checks

- [ ] App starts from a clean R environment
- [ ] All required packages are documented
- [ ] No local absolute paths
- [ ] No secret API keys committed
- [ ] All data files required for the demo are included or reproducibly generated
- [ ] Download buttons work
- [ ] Filters work
- [ ] Charts have clear labels and units
- [ ] Model metrics match the saved validation output
- [ ] Claims distinguish descriptive, predictive and causal statements

## Judge-facing checks

- [ ] Problem is explained in under 20 seconds
- [ ] NISR data source is shown
- [ ] One concrete agricultural decision is demonstrated
- [ ] ML validation is explained simply
- [ ] Innovation is demonstrated, not merely listed
- [ ] Tangible user impact is shown
- [ ] NST2/Vision 2050 alignment is visible
- [ ] Track 1 irrigation/soil-conservation relevance is clear

## Demo test

Use the same 90-second path every time:

Decision Center → District evidence → Validated ML → Targeting Lab → Scenario/Impact

## Final integrity rule

Never change, exaggerate or invent statistics to make the project look stronger. A smaller verified finding is more defensible than an impressive unsupported claim.
