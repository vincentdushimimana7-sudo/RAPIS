# RAPIS — WINNER — NISR 2026 Competition Version

## Start here

RAPIS is a Track 1 Agricultural Productivity solution for the **NISR 2026 Big Data Hackathon**.

The project has been deliberately aligned to the official 2026 evaluation criteria:

- Problem Understanding & Relevance — 20 points
- Data Use & Methodology — 20 points
- Tech Innovation — 20 points
- Usability & Design — 20 points
- Tangible Impact — 20 points

See `docs/NISR_2026_ALIGNMENT.md` for the detailed mapping and recommendations.

## Run the R/Shiny app

From the project root:

```r
source("r_shiny/install.R")
shiny::runApp("r_shiny")
```

## Track 1 scope coverage

Current evidence focuses on:
- small-scale irrigation;
- soil conservation/erosion evidence;
- agricultural productivity.

Planned modules are clearly labelled for:
- post-harvest collection and storage;
- processing/value addition;
- export-market opportunities;
- rainfall/climate;
- soil properties;
- terrain;
- satellite indicators.

Do not invent missing observations to demonstrate planned modules.

## Scientific integrity

Current data are aggregated and cover Season B 2026. The ML benchmark is predictive, not causal, and must not be presented as a future-harvest forecast without multi-season validation.
